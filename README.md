# Java Básico - Parte 3: Métodos

Coleção de exercícios em Java focados na criação e uso de métodos (com e sem retorno, parâmetros, sobrecarga implícita via varargs e recursão).

## Estrutura

Os exercícios estão na pasta `JavaBasicoParte3_Metodos/`:

| Arquivo | Descrição |
| --- | --- |
| [Ex01.java](Ex01.java) | Exibe um cabeçalho formatado de sistema (método `void`). |
| [Ex02.java](Ex02.java) | Calcula a média ponderada de duas notas (pesos 4 e 6). |
| [Ex03.java](Ex03.java) | Converte temperatura de Celsius para Kelvin. |
| [Ex04.java](Ex04.java) | Calcula o IMC (peso / altura²). |
| [Ex05.java](Ex05.java) | Retorna a classificação textual do IMC. |
| [Ex06.java](Ex06.java) | Verifica se um número inteiro é primo. |
| [Ex07.java](Ex07.java) | Calcula o MDC (Máximo Divisor Comum) entre dois inteiros. |
| [Ex08.java](Ex08.java) | Soma uma quantidade variável de inteiros usando varargs. |
| [Ex09.java](Ex09.java) | Conta a quantidade de vogais em uma string. |
| [Ex10.java](Ex10.java) | Inverte uma string. |
| [Ex11.java](Ex11.java) | Verifica se uma palavra/frase é um palíndromo. |
| [Ex12.java](Ex12.java) | Calcula juros compostos (`M = C * (1 + i)^t`). |
| [Ex13.java](Ex13.java) | Verifica se um ano é bissexto. |
| [Ex14.java](Ex14.java) | Converte um total de segundos para horas, minutos e segundos. |
| [Ex15.java](Ex15.java) | Obtém o N-ésimo termo da sequência de Fibonacci (recursivo). |
| [Ex16.java](Ex16.java) | Filtra e retorna um novo array contendo apenas os números pares. |
| [Ex17.java](Ex17.java) | Calcula a potência de um número de forma recursiva. |

## Como compilar e executar

Pré-requisito: [JDK](https://adoptium.net/) instalado e disponível no `PATH`.

No terminal, dentro da pasta `JavaBasicoParte3_Metodos`:

```bash
# Compilar
javac Ex01.java

# Executar
java Ex01
```

Substitua `Ex01` pelo exercício desejado. Cada programa solicita os dados necessários via entrada padrão (`Scanner`).
